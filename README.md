# AI Finance Tracker

AI Finance Tracker is a full-stack web application that helps users manage their personal finances efficiently. It allows users to track income, expenses, and visualize spending with AI-powered insights.

## 🚀 Features

- User Authentication (Upcoming)
- Add Income & Expenses
- Dashboard Overview
- Transaction History
- Expense Analytics
- AI Financial Insights (Upcoming)

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB (Upcoming)

## ▶️ Installation

```bash
npm install
```

Run frontend

```bash
cd client
npm run dev
```

Run backend

```bash
cd server
node server.js
```
