# AI Finance Tracker

AI Finance Tracker is a full-stack web application that helps users manage their personal finances efficiently. It allows users to track income, expenses, and visualize spending with AI-powered insights.

## 🚀 Features

- User Authentication (Upcoming)
- Add Income & Expenses
- Dashboard Overview
- Transaction History
- Expense Analytics
- AI Financial Insights (Upcoming)

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB (Upcoming)

## ▶️ Getting Started

1. Clone the repository and enter the project directory:

```bash
git clone <repository-url>
cd AI-Finance-Tracker
```

2. Install dependencies for the frontend and backend:

```bash
cd client && npm install
cd ../server && npm install
```

3. Start the development servers (run each in a separate terminal):

**Frontend**

```bash
cd client
npm run dev
```

**Backend**

```bash
cd server
npm run dev
```

The frontend runs at `http://localhost:5173` and the backend at `http://localhost:5000`.
